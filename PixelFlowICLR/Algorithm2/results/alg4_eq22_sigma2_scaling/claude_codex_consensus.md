## Claude 独立初判（Codex 回复前）

1. **缩放形式**：M̃v = (σ²/η²)AᵀAv + HᵀHv + σ²S⁻¹v；
   b̃ = (σ²/η²)Aᵀy + HᵀHx̂₁ + σ²S⁻¹x̂₁；
   ζ̃ = (σ²/η)Aᵀξ_y + σHᵀξ_h + σ²S^{-1/2}ξ_s。逐项正确。
2. **恒等式**：M̃=σ²M、b̃+ζ̃=σ²(b+ζ) 按构造精确成立（同一组 ξ 实现）。
3. **输出不变**：x = M̃⁻¹(b̃+ζ̃) = M⁻¹(b+ζ)——不仅分布相同，**同一实现**
   逐点相同（精确算术）；均值 M⁻¹b、协方差 M⁻¹M M⁻¹ = M⁻¹ 不变。
4. **随机 RHS 必须是 σ²ζ_τ（同一 ξ 缩放）**：若为 M̃ 重新构造 Cov=M̃ 的
   RTO 噪声 ζ'，则 Cov(x)=M̃⁻¹M̃M̃⁻¹=M̃⁻¹=M⁻¹/σ²——协方差被 1/σ² 放大
   （晚期高达 1e16 倍），错误。
5. **条件数不变**：κ(σ²M)=κ(M)（标量×SPD）；三项的**相对**量级比不变 ⟹
   fp32 的加法吸收（absorption）问题不因缩放改变。真实收益仅限中间量的
   动态范围：晚期 (1/σ²)HᵀHv ~1e16·v，reduction 的平方和可达 1e32-1e36，
   逼近 fp32 上限 3.4e38；缩放后同类中间量 O(1)。**要拿到这个收益,实现
   必须逐项重构（永不形成 1/σ² 中间量），事后乘 σ²·M(v) 无效**（大中间量
   已经出现）。
6. **停机/预条件**：相对残差在精确算术下缩放不变（r̃=σ²r、b̃=σ²b 同缩）。
   但实现里的三处绝对 clamp（1e-12）与 Jacobi floor（1e-12）**不是缩放
   不变的**——下缩后若 ||b̃||、p̃ᵀM̃p̃、r̃z̃ 落到 clamp 量级会改变迭代路径；
   晚期 ||b̃||≈σ²·O(1e16)=O(1)，初判安全，但需数值审计。Jacobi 对角按 σ²
   同缩、预条件方向 z=M̃_inv r̃ 与未缩放一致（M̃_inv=(1/σ²)M_inv、r̃=σ²r
   ⟹ z 不变）——预条件后的 CG 迭代在精确算术下**逐步等价**。spectral 探针
   各项若全部用缩放后算子构造则自动一致（d̃=σ²d）。
7. **附加初判**：逐项重构改变浮点运算顺序 ⟹ 即便数学恒等，开关打开后的
   轨迹与 baseline 只能在 fp 舍入级别一致（预期 max|Δ| ~1e-4 量级 fp32），
   不可能逐位相同——验证标准要按此设计（dense float64 恒等 + fp32 容差 +
   同种子 MC）。本方案定性为 **numerical rescaling**：不改变精确算术下的
   任何统计量，因此**原则上不可能解决 frozen-center**（那是精确算术性质）；
   唯一可能的真实收益是消除晚期 fp32 溢出/大中间量引起的实现层伪影。

## §3 共同解释 —— Claude 最终意见（codex 意见待其追加）

1. **严格保持原 Gaussian draw**：精确算术下逐实现恒等（稠密 fp64 9e-15）；
   fp32 下为同一目标的舍入级实现差。是。
2. **fp32 稳定性**：绝对动态范围收益真实且巨大（f39 2.9e7→4.6，σ=1e-8
   边界 4.6e16→4.6）；但当前生产调度最小 σ=4e-4、基线从未溢出全收敛 ⟹
   收益是**安全裕量**，不是修复了任何现存故障。
3. **CG 变化来源**：无系统性变化——迭代数几乎处处成对相等（差 ≤1 步），
   残差同量级；一步之差来自舍入路径不同的停机临界。
4. **轨迹差是否超界**：否。单步 relX ≤ 4e-4（慢收敛点）、端到端 2e-4~2e-3，
   与 GPU 非确定性底噪同量级，且 [T] 证明随 tol 收紧系统性缩小。
5. **是否设默认**：Claude 倾向**不设默认**——基线无现存数值故障，切换会
   使全部既有逐位基准失效（回归纪律成本 > 安全裕量收益）；保留为开关，
   在需要更小 sigma_min / fp16 / 更深调度时启用。待 codex 与用户裁决。
6. **定性**：只能称 numerical rescaling / 实现层数值稳健化。与 stage 2/3
   frozen-center 无关（那是精确算术性质，本改动精确算术下恒等）。
